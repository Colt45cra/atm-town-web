# ATM Town v235.6 — PWA + Player Pings

## Purpose
ATM Town can now be installed as a Progressive Web App and can deliver player-to-player pings through in-game realtime plus Web Push.

## PWA behavior
- `manifest.webmanifest` makes ATM Town installable with standalone display metadata and dedicated app icons.
- `service-worker.js` precaches the app shell and runtime-caches same-origin game assets.
- Streamed world chunks use stale-while-revalidate caching so repeat visits can start from local data while updated chunks refresh in the background.
- People Hub includes **Cache Game Data**, which explicitly preloads the streamed town world chunks after the player opts in.
- API/auth requests are never cached by the service worker.
- Service-worker deployment headers force prompt revalidation after new releases.

Installing the PWA does not blindly download every asset in the repository. Core files are precached, normal game assets are cached as used, and the optional Game Data action preloads the streamed town chunks. This avoids forcing large storage use on every device.

## Player pings
People Hub player rows include a **Ping** action with presets:
- Hey!
- Get on ATM Town
- Come find me
- Money Rain starting
- Custom message (120 characters maximum)

The authenticated ping API:
- never includes wallet addresses or wallet secrets,
- rate-limits the same sender/recipient pair,
- rate-limits total outgoing pings,
- records minimal ping audit rows server-side,
- sends Web Push only to subscriptions owned by the target ATM Town user.

If both players are currently in the same ATM Town realtime room, the sender also broadcasts the same server-created ping ID through Supabase Realtime for immediate in-game delivery. The client deduplicates the realtime and Web Push copies.

## Push notification behavior
- When ATM Town is visible, a push is routed into the game as an in-game Player Ping instead of creating a duplicate OS notification.
- When ATM Town is closed or backgrounded, the service worker displays an OS notification.
- Tapping the OS notification focuses/opens ATM Town.
- Multiple devices can subscribe to the same ATM Town account.
- Signing out unsubscribes the browser endpoint locally so a later user on the same device does not receive the previous user's pings.

On iPhone/iPad, Web Push requires ATM Town to be added to the Home Screen and notification permission must be granted from the installed web app.

## Server configuration
Before enabling push in production, configure ATM Town Vercel with:
- `WEB_PUSH_VAPID_PUBLIC_KEY`
- `WEB_PUSH_VAPID_PRIVATE_KEY`
- `WEB_PUSH_VAPID_SUBJECT=https://atm-town-web.vercel.app`

Generate a fresh keypair with:

```bash
node scripts/generate-vapid-keys.mjs
```

Never commit the private VAPID key.

## Database
Run `supabase/ATM-Town-v235.6.sql` in the ATM Town Supabase project. It adds server-only tables for device push subscriptions and ping rate-limit/audit records. RLS is enabled and no browser policies are created.
