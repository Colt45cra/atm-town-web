# ATM Town v235.11.3 — Mobile Attribute Store Payment Fit

## Purpose

Fix the mobile Attribute Store checkout section so no payment choices extend beyond the visible Store card.

## Changes

- CASH and CRYPTO are forced into equal flexible shares of the available mobile width.
- ATM, RLUSD, and XRP are forced into equal flexible shares of the available mobile width.
- Payment containers are explicitly width-bounded and clipped to the Store card to prevent intrinsic button sizing from widening the checkout area.
- The payment network note can wrap instead of forcing horizontal overflow.
- v235.11.2 Store close-button and vending input-guard behavior is preserved.

## Network policy preserved

- Attribute Store crypto purchases: XRPL Mainnet.
- Accepted current crypto rails: ATM, RLUSD, XRP.
- Receiving wallet: same wallet as Magnet Can vending.
- World-event funding/rewards: Testnet.

## Test

On a narrow phone viewport, open Attribute Store, add an item, select CRYPTO, and confirm CASH / CRYPTO and ATM / RLUSD / XRP are all fully visible without horizontal clipping.
