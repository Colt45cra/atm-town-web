# ATM Town v235.12.10 — Authoritative Prop Sync + Horde Pathfinding

## Summary

This build supersedes v235.12.9 before deployment. It keeps the authoritative Prop Hunt disguise synchronization and upgrades The Horde from mostly reactive wall avoidance to cached, throttled coarse route planning.

## Prop Hunt

- `event.prop_assignments[session_id]` remains the single disguise source of truth.
- Local and remote clients resolve each participant from the same server-backed assignment.
- Realtime player presence cannot override the assigned prop.

## Horde navigation

File: `js/zombie-outbreak.js`

When a zombie has a clear route, it still moves directly toward its target. When collision blocks that route:

1. The authority maps the zombie and target to a coarse navigation grid over the existing collision mask.
2. A bounded A* search finds a walkable route around the obstruction.
3. The raw grid route is simplified into line-of-sight waypoints.
4. The zombie follows those waypoints and returns to direct pursuit when practical.
5. If the target moves substantially or the zombie stops making progress, its cached route is refreshed.

### Performance protections

- Navigation runs only on the elected Horde authority.
- Existing routes are cached and reused.
- At most two new A* routes are planned per 120ms time slice.
- Each search has a hard node cap.
- Zombies waiting for a planning slot use the cheaper existing edge-follow steering instead of repeatedly recalculating.

This is intended to eliminate wall-pushing/left-right jitter without making a 60-enemy Horde expensive to simulate.

## Testing

### Prop Hunt
1. Confirm every device is on v235.12.10.
2. Start a new Prop Hunt.
3. Compare each hider's self-view with that hider on the other clients.
4. Confirm the disguise is identical everywhere.

### Horde navigation
1. Start The Horde with multiple players online.
2. Stand on the opposite side of a large building or long planter wall from several Horde enemies.
3. Confirm enemies turn and follow a route around the collision instead of pressing into the wall and rapidly switching directions.
4. Move along the far side of the obstacle and confirm routes update without obvious freezing.
5. Test with a large pack near the same obstruction and watch for smooth gameplay/no large lag spike.
6. Confirm remote clients see the same authoritative zombie movement.
