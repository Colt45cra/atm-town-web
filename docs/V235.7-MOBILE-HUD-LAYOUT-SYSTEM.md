# ATM Town v235.7 — Mobile HUD Layout System

## What changed

- Adds `js/hud-layout.js` as the single owner of mobile visual-viewport / software-keyboard geometry.
- Moves Chat and Voice into a vertical far-left rail directly above the joystick: Chat on top, microphone below.
- Anchors temporary HUD chat previews to the Chat button itself; previews are translucent, limited to two, and expire after 5 seconds.
- Keeps the normal message input + Send centered at the bottom while reserving the lower-right lane for the contextual Action button.
- When ATM TOWN LIVE opens, the existing single chat composer moves inside the live-chat panel, receives focus immediately, and the panel is sized against the real `visualViewport` while the keyboard animates.
- Live Chat renders before a message is sent and keeps its header, scrollable history, and composer visible above the mobile keyboard.
- Existing overhead player speech bubbles remain unchanged at roughly 6.5 seconds.
- Existing Trade Beacon showcase instruction text remains suppressed.
- World-event and player-ping notices now share HUD layout positioning variables instead of hard-coding unrelated top/bottom coordinates.

## Database / Payload

No SQL changes. No Payload changes. This is ATM TOWN ONLY.

## Test checklist

1. Confirm Chat is directly above the microphone on the far left, above the joystick.
2. Receive a chat message and confirm the translucent preview visually points to Chat and disappears at ~5 seconds.
3. Confirm the bottom message field + Send are centered and never occupy the Action lane.
4. Walk near an interactable and confirm the contextual Action button can appear at lower right without colliding with chat input.
5. Tap Chat and confirm ATM TOWN LIVE appears immediately, before sending anything.
6. Confirm the keyboard opens from that same tap and the full Live Chat panel remains above it.
7. Scroll chat history while the keyboard is open, send a message, then close the panel.
8. Confirm overhead speech bubbles are unchanged.
