# ATM Town v235.1 — Money Rain Polish

v235.1 keeps the v235 World Event Engine and preview-only reward model, while making Money Rain feel more like a live game event and less like an authored pickup test.

## Organic randomized layouts

Each event still receives a cryptographically random server seed, but the pickup manifest now uses an organic cluster/scatter generator. The server selects 4–7 random hotspot centers from a dense collision-authored safe-point pool, places most bills in uneven local clusters, and leaves the remainder as loose world scatter. The safe-point pool uses non-grid-aligned pixel coordinates generated from the exact town collision + stair masks, so repeated rows/columns are not authored into the event.

The same seed always produces the same event manifest for every client, while different event seeds produce different layouts.

## Faster pickup feel

The client now scans for pickups more frequently, uses a slightly more forgiving collection radius, and can claim several nearby bills in one authenticated request. As soon as the local player overlaps a pickup, it disappears immediately and shows collection feedback while the server confirms the claim underneath. The authoritative score is still reconciled from the server.

The server continues to verify event state, pickup identity, landing time, one-winner-per-pickup uniqueness, and proximity to each claimed pickup. Up to eight nearby pickup IDs can be processed in one claim request.

## Drop presentation framework

The existing 1,000 preview-point pool is unchanged, but its visual presentation now has reusable drop classes:

- common bills
- uncommon / rare bundles
- one jackpot money bag

These are Canvas-rendered placeholders. Custom ATM bills, project-branded money art, rare bag sprites, and other event assets can be swapped in later without changing the event manifest or scoring model.

## Sponsor / project attribution

The player launching Money Rain from the HQ ATM Command Core can choose either:

- their ATM Town player identity, or
- a custom project / brand label (2–32 characters)

The event HUD and announcements display `Money Rain provided by …`. Custom labels are display attribution only; the initiating authenticated ATM Town user remains recorded as the event sponsor on the server. URLs are rejected from the project / brand field.

## Reward safety

Real ATM/XRP/token settlement remains disabled in v235.1. Preview points are not redeemable. The browser still reports player position for proximity verification, so valuable rewards should not be attached until the later Reward Engine adds stronger position / anti-teleport authority.
