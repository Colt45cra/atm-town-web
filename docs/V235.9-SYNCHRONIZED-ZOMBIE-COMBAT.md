# ATM Town v235.9 — Synchronized Zombie Combat

## Goal
Zombie Outbreak now behaves as one shared multiplayer combat event instead of one local zombie simulation per device.

## Realtime authority model
- Every active outdoor player deterministically elects the same room combat authority from the currently known town participants.
- Only that authority advances zombie AI, HP, deaths, and collision-aware pursuit.
- The authority broadcasts compact zombie snapshots about eight times per second.
- Other clients interpolate toward those snapshots rather than independently deciding zombie movement.
- If the authority leaves the town or disconnects, the next eligible player takes over from the latest shared state.

This is intentionally a replaceable authority seam. A dedicated authoritative combat server can later own the same snapshot/input protocol for PvP and reward-sensitive combat.

## Shared firing
- Zombie weapon fire is relayed through the existing Supabase Realtime room.
- Default and Spread fire are sent per burst.
- Rapid Micro shots are batched into short packets to avoid flooding realtime while preserving the dense stream effect.
- Every client renders remote muzzle/projectile effects from the shared fire packet.
- Only the elected authority applies weapon damage to zombie HP.
- Shared snapshots then replicate the resulting HP/death state to every player.

## Zombie consistency
- The server-backed World Event Engine still creates the seeded 60-zombie spawn manifest.
- Spawn timing is tied to the server event timeline.
- Once spawned, zombie movement and HP come from the elected authority snapshots.
- Zombies target the nearest known outdoor player according to the authority's current multiplayer player positions.

## Existing combat preserved
- Four-way body animation.
- ±40° firing cone per body direction.
- Backpedal when moving opposite the firing direction.
- Strafing while aim remains independent from movement.
- Rapid Micro remains map-edge/extreme-range power.
- Spread remains devastating at close range.

## PvP boundary
v235.9 is designed for cooperative Zombie Outbreak synchronization. Do not treat client authority as cheat-resistant PvP. PvP should replace the elected browser authority with a dedicated authoritative realtime combat server while preserving the same client input/rendering protocol.
