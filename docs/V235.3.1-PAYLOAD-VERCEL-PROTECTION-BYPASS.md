# ATM Town v235.3.1 — Payload Vercel Protection Bypass

This hotfix preserves Payload Vercel Deployment Protection while allowing ATM Town server-to-server integration requests to reach Payload.

## Changes

- Adds optional `PAYLOAD_VERCEL_BYPASS_SECRET` support.
- Sends the secret only as the `x-vercel-protection-bypass` header on server-side requests to `PAYLOAD_API_BASE_URL`.
- Keeps ATM Town Ed25519 request signing unchanged; Payload still verifies the integration signature after Vercel admits the request.
- Improves structured Payload/Vercel API error rendering so objects no longer display as `[object Object]`.
- No wallet secret, seed, or private integration key is exposed to the browser.

## Deployment

Create a Vercel Protection Bypass for Automation secret on the Payload project, store that same value in the ATM Town Production environment as `PAYLOAD_VERCEL_BYPASS_SECRET`, then redeploy ATM Town.
