# ATM Town v235.12.6 — Prop Hunt Polish + Horde Darkness

## Summary

This build improves Prop Hunt readability and replaces cropped prop disguises with full standalone town props. It also makes The Horde nightfall much darker so visibility is constrained to the player light circle and street-lamp illumination.

## Prop Hunt changes

Files touched:
- `js/prop-hunt.js`
- `js/world-events.js`
- `lib/world-events.js`
- `service-worker.js`

Changes:
- removes the oversized live-round Prop Hunt panel from active gameplay
- leaves the compact top world-event HUD as the main live indicator
- keeps only a small completion/result card after the round finishes
- switches Prop Hunt disguises to full standalone ATM Town prop assets already used in the town map
- updates the server prop-assignment pool to match the new full prop ids

Current full-prop disguise pool:
- town directory kiosk (`assets_05_00.webp`)
- token market board (`assets_06_00.webp`)
- ATM vending machine blue (`assets_08_00.webp`)
- ATM vending machine green (`assets_09_00.webp`)
- street lamp (`assets_11_00.webp`)
- bench (`assets_18_00.webp`)

## Horde Nightfall changes

Files touched:
- `js/runtime/game-core.js`

Changes:
- increases Horde blackout strength
- reduces the player reveal radius
- changes the blackout rendering so the view is mostly covered first and then the player vision bubble is carved out
- keeps street-lamp illumination as the main outside-the-player visibility source

## Testing checklist

### Prop Hunt
1. Start Prop Hunt with at least 2 online players.
2. Confirm the oversized center/right Prop Hunt round panel no longer blocks gameplay.
3. Confirm the top Prop Hunt event bar still shows timer / role / props-left state.
4. Confirm disguised players appear as full standalone props rather than clipped object fragments.
5. Confirm found props still turn into seekers.
6. Confirm the final prop found is still announced as the winner.

### The Horde
1. Start The Horde in the town.
2. Confirm the town is significantly darker than before.
3. Confirm the local player can mainly see within their own light circle.
4. Confirm authored street lamps still illuminate their pools.
5. Confirm areas outside the player bubble and street-lamp pools are very difficult to see.
