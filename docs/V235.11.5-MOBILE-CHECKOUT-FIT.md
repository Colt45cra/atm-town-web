# ATM Town v235.11.5 — Mobile Checkout Fit

This patch fixes the remaining Attribute Store payment overflow seen on narrow mobile browsers.

## Fix

- Mobile shopping-cart layout is flattened from a nested grid to a block layout.
- CASH and CRYPTO are rendered in a hard two-column grid.
- ATM, RLUSD, and XRP are rendered in a hard three-column grid.
- Every payment button is explicitly width-bounded to its grid cell.
- Payment containers no longer use the previous nested flex sizing that could push later controls beyond the right edge.

## Preserved policy

- Attribute Store crypto purchases are XRPL Mainnet.
- ATM, RLUSD, and XRP remain the current crypto choices.
- The merchant receiver remains the same wallet used by Magnet Can vending.
- World-event funding and rewards remain on XRPL Testnet.
- v235.11.4 login/Enter Town stability and vending input protections remain intact.
