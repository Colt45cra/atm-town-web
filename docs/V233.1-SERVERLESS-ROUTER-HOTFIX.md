# ATM Town v233.1 — Vercel Hobby Serverless Router Hotfix

Vercel rejected v233 because the deployment contained more than 12 files under `api/`, which the Hobby deployment treated as Serverless Functions. v232.1 already used 12 API files; v233 added leaderboard/NFT offer routes and exceeded that ceiling.

## Changes
- Shared server helpers moved from `api/` to `lib/`.
- Xaman wallet-link start/status are multiplexed through `api/xaman-link.js`.
- Four XRPL NFT offer endpoints are multiplexed through `api/xrpl-nft-trade.js`.
- Original route logic is retained under `server/` and imported by the two routers.
- Front-end requests were updated to use `?action=` dispatch.
- Vercel API file count is now 11, leaving one Hobby-plan function slot available.
- Leaderboards, NFT collection, Trade Beacon, vending, wallet linking, LiveKit, and world streaming behavior remain otherwise unchanged.

## Important
The `scripts/apply-v2331.sh` cleanup script removes the obsolete v233 API files after the hotfix ZIP is extracted. This is necessary because leaving those old files in `api/` would still exceed Vercel's function limit.
