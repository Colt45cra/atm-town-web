# ATM Town v235.1.2 — Money Storm Density

This update increases the visual density of Money Rain without changing the server-authoritative reward pool.

- Keeps 84 collectible, server-authoritative Money Rain drops totaling exactly 1,000 preview points.
- Adds 168 decorative atmospheric bill trajectories around each active player viewport.
- Atmospheric bills continuously recycle from high above the camera so Money Rain reads as a persistent storm instead of occasional local drops.
- Decorative sky bills are never claimable and create no database writes or reward value.
- Existing organic hotspot/scatter collectible layout, sponsor attribution, rare collectible types, and v235.1.1 mobile-input fixes remain unchanged.
- Game runtime passes current camera/viewport dimensions to the World Event renderer so the decorative rain surrounds each player on phones, tablets, and desktop.

Real ATM/XRP/token settlement remains disabled.
