# ATM Town v235.12.2 — Flight FX Anchor Hotfix

## Scope

This is a focused rendering hotfix on top of v235.12.1.

### Inferno flight anchoring

`ATMZombieOutbreak.drawPlayerEffects()` now accepts the player's synchronized jump/flight lift. The Inferno particle origin uses the visual player Y position (`ground Y - jumpAmount`) instead of the ground Y position.

The runtime passes that lift for:

- the local player via `jumpLift()`;
- remote players via the synchronized `player_state.jump` value;
- outdoor Horde rendering;
- HQ, NFT Gallery, Arcade, and Lounge player render paths.

### Overhead chat flight anchoring

`drawChatBubbles()` resolves the current sender position every frame and now separately resolves the current airborne lift. The bubble anchor follows `player Y - lift`, so a message remains above the character during a jump, coast, rise, or fall.

The 420 px chat visibility test intentionally remains ground-plane distance. Jetpack altitude is a render offset, not world-map distance.

## Manual test

1. Enter ATM Town with two online players.
2. Activate Inferno on one player.
3. Activate the jetpack and rise high enough that the sprite is visibly separated from the ground position.
4. Confirm the Inferno fire remains attached to the airborne body while rising, coasting, and falling.
5. Confirm the second player sees the same attached Inferno position on the remote player.
6. While still airborne, send a short chat message.
7. Confirm the overhead message stays above the airborne sprite for both the sender and the other player.
8. Land and confirm both effects return naturally to the ground-level player anchor.
