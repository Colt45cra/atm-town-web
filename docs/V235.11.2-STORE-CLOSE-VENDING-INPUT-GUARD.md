# ATM Town v235.11.2 — Attribute Store UX + Vending Input Guard

## Purpose

Clarifies the Attribute Store payment UX before live checkout is enabled.

## Player-facing payment choice

The cart now first asks for **CASH** or **CRYPTO**.

- **CASH** — future USD/card checkout for players who do not use crypto.
- **CRYPTO** — XRPL Mainnet commerce. Current accepted assets are ATM, RLUSD, and XRP.

All three crypto assets are shown at once on mobile so none are clipped off-screen.

## Mainnet merchant destination

Attribute Store crypto purchases are pinned to the same destination already used by Magnet Can vending:

- ATM — issuer `raDZ4t8WPXkmDfJWMLBcNZmmSHmBC523NZ`
- RLUSD — official XRPL Mainnet issuer `rMxCKbEDwqr76QuheSUMdEGf4B9xJ8m5De`
- XRP — native XRP

## Network separation

Store purchases are **Mainnet**. Existing Money Rain / world-event reward infrastructure remains **Testnet** and is unchanged.

## Not live checkout yet

This patch does not submit payments. Prices and server-side permanent-purchase entitlements must be completed before checkout is enabled.


## v235.11.2 UX/input fixes

- Keeps the Attribute Store close control pinned to the upper-right corner of the Store card on desktop and mobile so horizontal catalog/cart content cannot push it off-screen.
- Adds an 850 ms vending open-gesture guard. A touch/pointer/click that opens a vending machine cannot immediately fire a synthetic/ghost close against the newly opened modal.
- Backdrop and Close Vending actions share the same guard; normal closing works after the opening gesture has settled.
- Commerce remains XRPL Mainnet. World-event funding/rewards remain Testnet.
