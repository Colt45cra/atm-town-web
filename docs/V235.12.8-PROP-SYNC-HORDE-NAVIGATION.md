# ATM Town v235.12.8 — Prop Sync + Horde Navigation

## Prop Hunt

### Prop scale
The verified full-map disguise assets now render at 1.0 authored scale. Previous 0.82–0.92 scaling made them visibly smaller than the same objects placed in the world.

### Cross-client disguise synchronization
`ATMPropHunt.getBroadcastState()` publishes the active event id, the player's current Prop Hunt role, and the exact prop id being rendered. The normal multiplayer `player_state` packet carries this state. Remote rendering uses the broadcast prop only when its event id matches the locally active Prop Hunt event; otherwise it falls back to the server assignment.

This makes the same hidden player render as the same prop on every client while keeping the server event assignment as the source of truth/fallback.

## The Horde obstacle avoidance

The elected Horde authority now performs lightweight local navigation for every zombie:
- forward path probes against the existing town collision mask
- zombie-footprint side probes rather than center-point-only checks
- persistent wall-following side selection to avoid left/right oscillation
- angled steering candidates around the direct target line
- stuck detection that flips the wall-following side when necessary
- diagonal movement with axis sliding at tight collision edges

Only the elected authority performs this navigation. Existing compact zombie snapshots continue broadcasting the authoritative positions to every other client.

## Testing

### Prop Hunt
1. Start a round with at least two clients.
2. Compare one hidden player's disguise on their own screen and on another player's screen.
3. Confirm both clients show the exact same prop.
4. Confirm the prop is approximately the same size as the identical placed map object.
5. Confirm found props still become seekers and the final prop found still wins.

### The Horde
1. Start The Horde near a large building or planter cluster.
2. Stand on the opposite side of the obstacle from a group of zombies.
3. Confirm they turn and travel around the obstacle instead of continuously walking into the collision boundary.
4. Move around corners and verify zombies reacquire the direct path when it opens.
5. Compare two clients and confirm synchronized zombie positions remain consistent.
