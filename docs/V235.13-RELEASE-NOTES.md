# v235.13 Release Notes

This release improves XRPL NFT loading and establishes ATM Town as the canonical identity backend for standalone ATM Pay.

## NFT improvements

- persistent local presentation-metadata cache keyed by NFTokenID + URI;
- higher metadata hydration concurrency;
- fewer expensive full-grid redraws;
- faster IPFS candidate ordering;
- Trade Beacon image timeout/fallback behavior to prevent permanent loading spinners;
- active Trade Beacon refresh when metadata resolves.

## Shared ATM identity

- canonical ATM Town Auth users shared with standalone ATM Pay;
- RLS-protected encrypted wallet backup and route tables;
- canonical ATM Pay handles with legacy-handle aliases;
- compatibility view/RPCs for the standalone app;
- existing encrypted standalone wallet records migrated without plaintext secrets;
- legacy standalone database retained as rollback source.

WebAuthn RP configuration is intentionally unchanged in this release to preserve existing ATM Town passkeys.
