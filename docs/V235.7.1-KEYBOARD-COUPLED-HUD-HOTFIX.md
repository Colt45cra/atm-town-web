# ATM Town v235.7.1 — Keyboard-Coupled HUD Hotfix

This hotfix tightens the v235.7 mobile HUD around real phone keyboard behavior.

## Changes

- ATM TOWN LIVE is no longer allowed to remain visibly open on a touch device without the software keyboard.
- Opening Live Chat focuses the chat input immediately and retries focus during the keyboard animation.
- If the software keyboard fails to appear, Live Chat closes instead of leaving an unusable chat-only panel on screen.
- Dismissing the phone keyboard while Live Chat is open closes Live Chat as well.
- Live Chat uses a translucent panel so the ATM Town game world remains visible behind it.
- The game canvas no longer resizes down to the keyboard-sized visual viewport. The keyboard changes HUD geometry, not the game rendering surface.
- Quick chat keeps the game world visible above the keyboard instead of exposing the page background.
- While quick chat is actively being typed, joystick/social/action controls fade out so the reduced visible area belongs to the game and composer.
- Quick-chat composer and the left Chat/Mic rail follow the actual visual viewport.
- PWA build files now use network-first fetches and an existing installed app reloads once when a new service worker takes control, reducing mixed-version cache states after deploys.

## Preserved behavior

- Chat button remains above the microphone on the far left above the joystick.
- Temporary chat previews remain anchored to the Chat button and expire after about five seconds.
- Normal gameplay text input + Send remain centered with the contextual Action lane reserved on the right.
- Overhead player speech bubbles retain their existing behavior.
- Persistent session/recent Live Chat history is unchanged.
