# ATM Town v235.4 — Xbox Controller Support

ATM Town now supports standard-mapped game controllers through the browser Gamepad API, with Xbox One / Xbox Series controllers as the primary target on desktop Chrome and Edge. Controller input is additive: keyboard, mouse, touch, and controller can be switched between at any time.

## World controls

- Left stick: analog movement
- D-pad: digital movement fallback
- Right stick: camera look offset
- A: jump; press again while airborne with a jetpack to start thrust
- RT: alternate airborne jetpack thrust; release to stop thrust
- X: contextual world action / interact
- Y or View: open map / directory
- LB or Menu: open People Hub
- RB: open Locker
- B: close / back from supported UI panels

A radial dead zone prevents stick drift. Controller prompts replace touch-oriented prompts after the controller is used, and a short connection banner confirms the active mapping.

## UI navigation

When a supported ATM Town modal is open, the left stick or D-pad moves focus, A/X activates the focused control, LB/RB can step focus, and B closes or backs out. The controller focus ring is intentionally high-contrast.

## Arcade compatibility

The controller bridges left-stick movement and A/Space behavior into keyboard-compatible arcade games: Sky Run, Platform Panic, Ring Rumble, and Flappy Jetpack. ATM Darts keeps its pointer/flick throwing mechanic; controller buttons can navigate/close its lobby but throwing still requires pointer/touch input in this release.

## Safety / compatibility

- Uses `navigator.getGamepads()` and standard Gamepad mapping only; no controller permissions or native software are required by ATM Town.
- Disconnecting a controller clears movement and synthesized arcade key state so input cannot stick.
- Gamepad input is suppressed for world movement while supported modal UI is active.
- Existing keyboard, touch joystick, mobile jump, jetpack, and Payload/Money Rain logic is unchanged.
