# ATM Town v235.9.4 — Horde Nightfall

This update is intended to be applied directly over the uploaded live v235.9.2 source and includes the v235.9.3 Horde grounding/animation changes.

## Horde Nightfall

- While The Horde is active and the local player is outdoors in ATM Town, the normal shared day/night alpha is overridden to full night.
- The change fades in quickly at event start and fades back to the normal shared world cycle after the event ends.
- A second darkness pass restricts the local player's usable vision to a radial area around their character.
- The existing authored streamed `lighting` layer remains in use; no lighting-mask artwork is replaced.
- During The Horde only, the authored street-light illumination layer flickers with a failing-grid effect. Flicker timing is based on the shared world server clock so connected players see the same power fluctuations.
- Street-light illumination is drawn after the Horde darkness pass so existing illuminated areas can still puncture the blackout.

## Preserved behavior

The event manifest, Horde count, AI, spawning, collision, weapons, hit logic, rewards, event duration, ATM HQ trigger, elected multiplayer authority, shared zombie snapshots, and shared firing effects are unchanged.

The v235.9.3 Horde sprite grounding and full 3-frame playable-character walk cycle remain included.
