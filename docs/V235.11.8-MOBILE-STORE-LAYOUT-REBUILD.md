# ATM Town v235.11.8 — Mobile Store Layout Rebuild

## Problem
The v235.11.7 cart width fix contained the checkout CTA, but the mobile product grid could still establish a layout wider than the visible Store card. Product art and Add to Cart controls could therefore render off-screen.

## Fix
- Mobile Store uses a flex-column application layout rather than a grid plus an absolutely positioned cart.
- Header, character tabs, filters, cart CTA, and footer are fixed-height sections.
- Only the product catalog scrolls.
- Product catalog uses a single vertical flex list on mobile.
- Product cards use an 86 px art column plus a `minmax(0, 1fr)` detail column.
- Mobile product cards and action buttons use normal stretch/auto sizing rather than percentage widths.
- The cart CTA is static in document flow, so it cannot inherit product-grid intrinsic width.

## Preserved behavior
- Dedicated Review Payment checkout sheet.
- Cash/Card and Crypto checkout choices.
- ATM, RLUSD, and XRP Store crypto rails on XRPL Mainnet.
- Same merchant wallet policy as Magnet Can vending.
- World-event funding/rewards remain XRPL Testnet.
- NFT-backed entitlement behavior and owned-only Locker behavior remain unchanged.
