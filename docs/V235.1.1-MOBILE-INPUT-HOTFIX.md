# ATM Town v235.1.1 — Mobile Input + Money Rain Hotfix

This hotfix targets iPhone/Safari input behavior and improves Money Rain atmosphere without changing the 1,000-point preview pool or enabling token settlement.

- World Event sponsor/project text entry is no longer destroyed by background event polling while focused.
- Mobile/coarse-pointer canvas pinch zoom is disabled to prevent accidental in-game camera zoom during multi-touch play. Desktop wheel/trackpad zoom remains.
- Joystick state resets on pointer cancel, lost capture, window blur, visibility changes, and matching global pointer release.
- Dynamic text fields release movement/jetpack controls on focus.
- Game chrome disables text selection and iOS touch callouts; text inputs and explicit copy surfaces remain selectable.
- Mobile text inputs use at least 16px type to avoid Safari focus auto-zoom.
- World Event panel sizing follows the visual viewport while the software keyboard is open.


Money Rain presentation improvements:

- 84 total preview pickups now share the same 1,000-point pool, creating more visible bills without increasing rewards.
- Dense organic hotspots remain, but roughly 26–34 pickups are deliberately spread around the wider map between clumps.
- Loose-scatter selection prefers safe locations away from hotspot centers and other loose drops before relaxing constraints, avoiding obvious rows and local over-concentration.
- Drops begin roughly 900–1600 world pixels above their landing point and fall for roughly 2.8–4.6 seconds with randomized flutter/drift, so money is visibly raining through the air instead of appearing just above the ground.
- Event positions and timing remain deterministic from the server event seed so all players see the same rain.
