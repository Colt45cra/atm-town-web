# ATM Town v235.10 — You Are ATM NFT Entitlements

## Goal

Connect the existing ATM Town Locker equipment system to current ownership of the **You Are ATM** XRPL NFT collection so holder attributes become usable in game while non-starter cosmetics become store inventory.

## Collection source of truth

- XRPL network: Mainnet through the existing verified Xaman-linked wallet flow
- Issuer: `rsQJqZ7gbHR8hAfWP2fSzY2Zbg6akcMd2H`
- Taxon: `1`
- The linked wallet inventory is still loaded by the authenticated `/api/xrpl-inventory` endpoint from a validated ledger.
- NFT metadata is still resolved through the authenticated `/api/xrpl-nft-metadata` endpoint.

## Entitlement rule

ATM Town combines traits from every currently owned NFT matching the collection issuer + taxon. A mapped trait unlocks the corresponding Locker item. The entitlement is current-ownership based: if the wallet no longer owns the NFT that supplies the trait, the item becomes locked again after ownership refresh.

The mapping is intentionally explicit rather than fuzzy. Trait type and value must match an allowlisted alias for an ATM Town item; unrelated NFT text cannot accidentally unlock equipment.

## Initial mapped equipment

The first mapping pass covers the existing headgear catalog, Green / White / Yellow katanas, Jetpack, Gold Face, matching backpack aliases, several face-emote aliases, Boxing Gloves, and confirmed color aliases already represented by current ATM Town art.

Examples:

- `Head: Paper Hat` → `head:paper-hat`
- `Katana: Green` → `back:green-katana`
- `Katana: White` → `back:white-katana`
- `Katana: Yellow` → `back:yellow-katana`
- `Back: Jetpack` → `equipment:jetpack`
- `Face: Gold` → `face:gold`
- `Back: Blue Yellow Backpack` → `backpack:blue-yellow`
- `Back: Yellow Purple Backpack` → `backpack:gold-purple`

More aliases can be added to `ATM_YOU_ARE_ATM_TRAIT_RULES` as holder wallets expose the exact collection metadata values.

## Locker behavior

- Starter playable characters remain free.
- Previous `DEV GRANT` equipment is converted at runtime to store-locked inventory.
- A mapped trait displays `NFT OWNED` (or a quantity if multiple NFTs supply it).
- While collection metadata is still resolving, mapped items display `VERIFYING NFT` rather than incorrectly claiming ownership.
- Store-only items display `STORE LOCKED`; mapped-but-unowned items display `STORE / NFT`.
- The Inventory summary now shows total XRPL NFTs, You Are ATM NFTs, NFT-unlocked game items, owned items, and equipped slots.
- Selecting a You Are ATM NFT in the NFT tab shows whether it unlocks ATM Town gear and lists the mapped game items.
- Equipment that loses its verified entitlement is removed from the active loadout after the ownership refresh settles.

## Jetpack entitlement

`Back: Jetpack` is a permanent gameplay entitlement while the NFT is currently owned **and the Jetpack is equipped in the Locker**. This does not remove the existing vending-machine system:

- NFT holder + Jetpack equipped → permanent Jetpack access.
- Non-holder → existing temporary vending Jetpack time still works.
- An NFT Jetpack can be equipped/unequipped like other permanent gear.
- Multiplayer continues to use the existing jetpack/loadout state broadcast.

## Commerce boundary

v235.10 is the entitlement + store-lock foundation. It intentionally does **not** accept new direct cosmetic payments yet. Permanent purchases must be persisted and transaction-validated server-side; the checkout destination, prices, currency choices, and purchase schema belong to the next commerce patch after this entitlement pass is verified against real holder wallets.

No Supabase SQL migration is required for v235.10.

## Test checklist

1. Deploy v235.10 and hard-refresh/relaunch the PWA so the new shell cache is active.
2. Sign in with an ATM Town account whose verified Xaman wallet owns at least one You Are ATM NFT.
3. Open Locker and tap **REFRESH XRPL**.
4. Confirm the Inventory summary counts the wallet's You Are ATM NFTs.
5. Confirm mapped attributes from all owned collection NFTs become `NFT OWNED` in the Locker.
6. Equip a mapped head item / katana / Gold Face and confirm it renders normally.
7. If the wallet has `Back: Jetpack`, equip it and confirm the Jetpack HUD reads `NFT` and has no countdown.
8. Confirm an unmapped/unowned cosmetic is store-locked.
9. Open the XRPL NFT tab, select a You Are ATM NFT, and confirm the detail panel lists the ATM Town items that NFT unlocks.
10. Test a wallet without the collection and confirm it does not receive You Are ATM entitlements.
11. Preserve and retest v235.9.4 Horde Nightfall, shared Horde combat, PWA, People Hub, and normal vending power-ups.
