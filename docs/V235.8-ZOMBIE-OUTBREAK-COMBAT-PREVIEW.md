# ATM Town v235.8 — Zombie Outbreak Combat Preview

## Purpose

v235.8 adds the first reusable combat layer to ATM Town as a World Event. The event is launched from the ATM Command Core inside ATM HQ and uses the existing server-backed World Event slot so it cannot overlap another active Money Rain / Zombie Outbreak.

## Event flow

- Launch location: ATM Command Core inside ATM HQ.
- Countdown: 15 seconds, giving the starter time to exit HQ.
- Fight duration: 90 seconds.
- Outdoor town only.
- 28 red-box zombie stand-ins use a seeded server manifest and staggered spawn offsets.
- No XRP or ATM reward settlement is attached to this preview.

## Combat controls

ATM Town keeps its existing four-direction character sprite sheets while movement and aim remain independent. During active firing, aim owns body facing. The gun can aim up to 40 degrees to either side of the current cardinal facing direction. Crossing into the next sector rotates the body. A player moving opposite the shot direction keeps facing the weapon and reverses the walk-cycle to read as backpedaling; perpendicular movement reads as strafing.

Mobile uses the existing left movement stick plus a temporary right AIM / FIRE stick during Zombie Outbreak. Xbox-style controllers use the right stick for aim/fire instead of camera look while the event is active. Desktop can hold the primary mouse button on the world to aim and fire.

## Weapons

All players start with the default blaster. World-event ground pickups switch the local combat weapon.

### Rapid Micro (R)

- Extremely high fire rate.
- Damage ray reaches toward the map edge, stopping at solid world geometry.
- Damage remains at full power until extreme distance (roughly the final 12% of maximum map-diagonal range), then falls only modestly.
- Rendering uses many tiny ultra-fast streaks instead of a large visible projectile.

### Spread (S)

- Seven-pellet fan.
- Devastating close-range damage and strong medium-range damage.
- Damage falls substantially near the outer edge of its shorter range.

## Synchronization boundary

The server synchronizes the event ID, countdown, start/end times, seed, zombie spawn manifest and weapon pickup locations through the existing World Event Engine. In v235.8, zombie movement, HP, hits and kills are intentionally resolved client-side. This is a gameplay/controls preview, not authoritative competitive combat.

That boundary is intentional: `js/zombie-outbreak.js` owns combat input/render/resolution behind a focused API. A later realtime authoritative combat server can replace hit/zombie/player-state authority for synchronized PvP and rewarded combat without replacing the approved movement, ±40° facing system, backpedal behavior or weapon feel.

## Temporary art

Zombies are rendered as depth-sorted red boxes with health bars until dedicated zombie character art is supplied. They are inserted into the same outdoor depth sort as players, bots and foreground pieces.
