# ATM Town v235.6.2 — Persistent Live Chat

ATM Town now separates short spatial speech bubbles from readable session chat.

- Overhead speech bubbles keep the existing ~6.5 second lifetime.
- The collapsed on-screen preview keeps new messages visible for up to 5 minutes.
- A Live Chat button opens a scrollable panel with the current play session's messages.
- Authenticated players joining online receive up to the last 10 minutes / 100 messages for context.
- The browser keeps up to 200 messages for the current play session.
- The API stores only authenticated messages, rate-limits recent posting, and opportunistically deletes server history older than one hour.
- The Supabase table has RLS enabled with no browser policies; server service-role access is used.
- Guest multiplayer chat still works in realtime and remains session-local, but is not added to server recent history.
- Message text is limited to 180 characters and rendered with textContent.
