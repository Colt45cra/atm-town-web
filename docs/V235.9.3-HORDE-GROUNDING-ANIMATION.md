# ATM Town v235.9.3 — Horde Grounding & Animation

This hotfix keeps the existing synchronized Horde event/combat design intact and corrects only Horde sprite presentation/synchronization.

- Horde sprite sheets continue to use the same 3-column × 4-row contract as playable characters: down, left, up, right; frame 1 is idle.
- Walking now uses the same full `0 → 1 → 2` frame cycle and 8 Hz animation cadence used by playable characters instead of alternating only the two outer frames.
- Horde sprites now use the playable-character ground-foot placement (`y + 34`) and the same grounded shadow convention, eliminating the visual hover above the map/shadow.
- Idle Horde characters no longer run a perpetual vertical bob. Walking bob is only applied while the actor is actually moving.
- The elected combat authority now includes direction, moving state, and animation phase in compact Horde snapshots so non-authority multiplayer clients animate/facing the shared Horde correctly instead of receiving position/HP only.
- Existing Horde spawns, targeting, combat authority, weapons, HP/damage, event timing, and backend event type are unchanged.

## Superseded packaging note

The v235.9.4 change package includes all v235.9.3 grounding/animation changes, so users coming directly from live v235.9.2 do not need to apply a separate v235.9.3 ZIP first.
