# ATM Town v235.7.2 — Live Chat Send + Panic Jetpack

## Live Chat

- The visible **SEND** button no longer steals focus from the Live Chat text field on touch devices.
- Tapping either the in-window SEND button or the keyboard Send/Enter action now uses the same message flow while keeping ATM TOWN LIVE and the software keyboard open.
- After a send, the Live Chat input is re-focused and the HUD viewport is re-synchronized.
- The `No messages yet` empty state is explicitly hidden whenever session/history messages are present.

## Platform Panic — 440m Jetpack Phase

- At **440 meters**, every run automatically unlocks the Platform Panic jetpack; it does not depend on the player's town loadout.
- The jetpack is a late-run survival mechanic designed to help the player stay ahead of the accelerating lava without removing platform gameplay.
- Hold the normal jump control (Space/W/Up on desktop, or hold the play area on touch) while airborne to thrust.
- Jetpack fuel lasts **1.6 seconds per landing** and fully refills whenever the player lands on a platform.
- The standard ATM jetpack overlay and thrust flame are shown while the ability is equipped/active.
- A one-time 440m unlock banner explains the new controls, and the ability HUD shows remaining fuel percentage.

## Deployment

No database migration or Payload change is required.
