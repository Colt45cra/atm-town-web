# ATM Town v235.1.3 — Locker Presence & Interior Resume

This hotfix preserves multiplayer presence and proximity voice while the Locker is open, repairs building return-position persistence across app/background restarts, and slows the v235.1.2 decorative Money Storm without changing its density.

## Locker presence

- Opening Locker now publishes an `activity.type = locker` multiplayer state.
- Remote players continue to render the character at the player's real map position.
- The existing player nameplate displays `IN LOCKER` while that activity is active.
- Modal UI continues the normal throttled player-state heartbeat instead of allowing the remote state to expire.
- LiveKit remains connected; proximity voice continues to use the player's unchanged map position.
- Closing Locker restores the prior activity state and broadcasts immediately.

## Interior resume / exit return

- Account-location persistence now stores the current interior's town return point when one exists.
- Restoring inside HQ, Gallery, Arcade, or Lounge restores that exterior return point before the player exits.
- Older saved interior sessions without a persisted return point reconstruct the proper exterior doorway from the central map/entrance registry.
- Restoring directly into town clears stale interior return data.

## Money Storm speed

- Atmospheric object count remains exactly 168.
- Collectible drop count remains exactly 84.
- The 1,000-point preview pool is unchanged.
- Decorative money now spends roughly 6.6–11.4 seconds airborne per cycle instead of the faster v235.1.2 timing.
- Flutter and rotation are slowed so bills drift rather than streak downward.

## Unchanged systems

No SQL changes. No XRPL settlement changes. ATM Pay, embedded wallet security, People Hub, Trade Beacon, score reliability, streamed world, characters, and server-authoritative Money Rain collectibles remain unchanged.
