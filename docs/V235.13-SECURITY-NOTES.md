# v235.13 Security Notes

- XRPL NFT metadata cache stores public presentation metadata only; ownership remains ledger-authoritative.
- Shared wallet backup records remain encrypted client-side.
- Canonical wallet-backup table constraints reject common plaintext secret fields.
- Browser access to wallet data is limited by RLS to `auth.uid()` ownership.
- Legacy handle aliases are server-managed.
- WebAuthn RP ID is unchanged to avoid invalidating enrolled passkeys.
