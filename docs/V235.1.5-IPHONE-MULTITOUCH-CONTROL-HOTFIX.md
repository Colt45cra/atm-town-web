# ATM Town v235.1.5 — iPhone Multi-Touch Control Hotfix

## Fix

This hotfix corrects a regression introduced by the v235.1.4 native Safari zoom guard.

On iPhone, holding the movement joystick and then touching the game canvas to jump can cause Safari to emit a native gesture event. v235.1.4 prevented the browser zoom but also called `endJoy()`, which zeroed movement until the player released and touched the joystick again.

v235.1.5 keeps the native Safari page-zoom prevention but **never releases the joystick from the gesture guard**. The joystick finger retains pointer ownership while a second finger taps/holds Jump.

No Money Rain, Locker, voice, ATM Pay, world-event, map, or XRPL behavior is changed by this hotfix.
