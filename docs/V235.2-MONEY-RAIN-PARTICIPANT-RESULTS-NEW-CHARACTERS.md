# ATM Town v235.2 — Money Rain Participant Results + New Characters

## Money Rain result semantics

Money Rain is **not winner-take-all**. Every authenticated player who successfully claims at least one collectible receives a finalized participant result containing their rank, collectible count, and total collected preview points. First place remains a leaderboard distinction only.

The server keeps every accepted pickup claim in `world_event_claims`. Completed event state now exposes all public participant results (without Supabase user IDs), the requesting player's own rank/score, participant count, total claimed points, and the unclaimed remainder.

Future Project Payload settlement must use `settlement_basis = collected_points`: each player is paid according to what that player actually collected. Unclaimed funded value is not redistributed to first place; it remains in/refunds to the sponsor reward pool (`unclaimed_policy = sponsor_remainder`).

Real XRPL settlement remains disabled in this build pending the Project Payload integration.

## Personal-score reliability

An invalid/expired Bearer token on the World Event GET route no longer silently becomes anonymous state. Public fallback state is explicitly marked as lacking a personal score, and the browser preserves the last authenticated score instead of overwriting earned points with zero.

## New playable characters

Added as starter characters using ATM Town's 768×1280, 3-column × 4-row sprite-sheet standard (256×320 frames; Down / Left / Up / Right):

- Salute
- Brad
- David
- Kaj

Each is integrated into signup character selection, profile switching, saved-character validation, multiplayer rendering, and the Locker starter catalog. Playable sheets and idle thumbnails use lossless WebP.
