# ATM Town v234.4 — People Hub

## Goal
Replace proximity-triggered PAY action-ring behavior with one persistent social entry point: the existing online-player count badge.

## Sliding pages
- **Online** — all currently visible multiplayer players, with nearby players sorted first. ATM Pay-enabled players can be selected for payment.
- **People** — recent ATM Pay contacts plus ATM Pay-enabled players encountered during the current browser session. Encounter history is session-scoped, not a permanent proximity log.
- **Pay** — pending payment requests, ATM Pay search, and recent activity. The full ATM Pay security/payment UI remains available from this page.

## HUD behavior
The existing online count is now clickable. A small green indicator appears when another player is nearby. Pending ATM Pay requests add a numeric badge. No extra permanent ATM Pay HUD icon is added.

## Interaction ring
ATM Pay no longer competes for the world ACTION ring. Trade Beacon, vending machines, doors, games, NPCs, and other physical world interactions retain the ring.

## Privacy
Multiplayer continues to broadcast only public ATM Pay identity fields. XRPL addresses are not broadcast. Session encounter history contains only public player/payment identity and is stored in sessionStorage, which is scoped to the browser session.

## Friends
The current build does not have a friend-request backend, so v234.4 labels the middle page **People** instead of pretending recent contacts are friends. A true Friends system can be added later without changing the hub layout.
