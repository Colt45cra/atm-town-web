ATM TOWN v231 — XRPL NFT COLLECTION

This build is based on the v230 streamed-world repository and adds the Phase 1 read-only XRPL NFT Collection.

For a full-build replacement:
1. Extract the v231 full ZIP.
2. Upload/replace its CONTENTS in the root of the ATM Town GitHub repository.
3. Preserve the folder structure exactly:
   /api
   /assets
   /docs
   /js
   /scripts
4. Commit the v231 files together so index.html, js/config.js, and the new XRPL API endpoints stay in sync.

For an incremental update from the exact v230 build used as the source of truth, the changed-files package is preferred. It contains only the files added/modified for v231.

TEST AFTER DEPLOYMENT:
- Sign in with an account that has a verified Xaman wallet.
- Open Locker -> XRPL NFTs.
- Confirm the wallet and on-ledger NFT count load.
- Open several NFTs and confirm metadata/artwork gracefully loads or falls back.
- Confirm SHOWCASE / TRADE / SELL are visible but disabled in Phase 1.

IMPORTANT ASSET FORMAT RULE:
- Visual artwork: WebP when appropriate.
- Collision/interaction/stair/depth/pixel-data masks: PNG.
